# Security Policy

## Supported Versions

BSSCL-GBM is currently in active development. Security updates will only be applied to the latest major release branch.

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |
| < 1.0.0 | :x:                |

## Reporting a Vulnerability

Security is a high priority for the BSSCL-GBM project. If you discover a vulnerability, we would like to know about it so we can take steps to address it as quickly as possible.

**Please do not report security vulnerabilities through public GitHub issues.**

Instead, please report them directly to the author: Bhaskar via private communication or email if listed on the PyPI author profile. 

When reporting a vulnerability, please include:
- A description of the vulnerability and its impact.
- Steps to reproduce the vulnerability (a reproducible script is highly appreciated).
- Any proposed fix or mitigation.

The project maintainer will acknowledge your report, investigate the issue, and push a patch to the repository. Public disclosure will be coordinated only after a patch is released on PyPI.
